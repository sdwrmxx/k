Pattern syntax
  • {l} lowercase letter, {u} uppercase letter
  • {d} digit, {s} special character
  • {word} random word, {Word} capitalized, {WORD} uppercase
  • repeat a code for more of it: {dddd} is 4 digits, {llll} is 4 letters
  • anything else in the pattern (-, ., spaces…) is kept as-is
